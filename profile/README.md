<h1 align="center">Winix</h1>

<p align="center"><strong>A familiar desktop experience for Linux.</strong></p>

Winix is an independent open-source project built on KDE technologies. It brings a consistent experience to everyday file management, file-operation progress and the KDE Plasma desktop.

## Our applications

| Application | What it does |
| --- | --- |
| **Winix Explorer** | A Linux file manager built on KDE Dolphin, with familiar navigation, tabs, split views, a command ribbon and integrated **Winix Preview** for documents, images, archives, audio and video. |
| **Winix Copy** | A dedicated window for KDE file-operation progress, with transfer graphs, supported pause and cancel controls, and operation logs. |
| **Winix Desktop** | A KDE Plasma desktop extension with classic context menus, document templates, familiar desktop shortcuts and reversible activation. |

Winix Preview is part of Winix Explorer's file-management experience.

## Our focus

- Familiar, practical workflows for everyday desktop tasks.
- A consistent experience across the three Winix applications.
- KDE integration that preserves native file-operation behavior.

Development currently targets **Debian 13 with KDE Plasma 6**. Installation, compatibility and release details are documented per application.
